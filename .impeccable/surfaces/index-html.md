# Surface brief — index.html (portfolio home)

Scope: single static page (About, Experience, Research, Projects, Skills, Contact).
Visitor mode: Experience. Audience: recruiters skimming in seconds; action is contact.
Constraints: static files on GitHub Pages; all copy/facts frozen; resume download,
theme toggle, and contact paths keep working.

## Direction contract

THESIS: Harbor bones, arcade pulse. The page keeps the category-standard
recruiter skeleton — rails, numbered sections, tabbed experience, featured
project rows — but speaks in arcade's voice: heavy display type, a committed
multicolor accent family, and one rotating badge. It refuses both the generic
dark-gradient portfolio and the all-playful sticker book.

OWN-WORLD: Deep-navy ground with a paper-light twin. Archivo Black display,
Inter body, JetBrains Mono for data and labels only. Six matte arcade accents
assigned per project and section; yellow carries the primary action with navy
ink. Stickers keyed by a thin top color bar; chips for skills; SVG icon rails.

STORY: A recruiter reads name, proof, and contact inside one viewport, then
scans numbered evidence: tabs for roles, rows for flagship builds, chips for
stack. The badge signals availability without asking for attention.

FIRST VIEWPORT: A quiet introduction, not a pitch. Mono greeting, the name
set large, one short paragraph (UCI CS, local-first ML, first-author IEEE
ICCE 2025 paper on sign-language video translation), and a plain row of text
links: Email, GitHub, LinkedIn, Resume. No claim headline, no buttons, no
badge. Light paper ground only; the dark theme was removed per user request.

FORM: Canon fusion of two built variants (harbor structure + arcade voice),
chosen by the user from three canon executions. seed: none (canon — no
direction roll applies; choice recorded via concept-seed telemetry --kind canon).

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance
